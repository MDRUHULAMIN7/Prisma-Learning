# Learning Notebook

A small Next.js notebook for collecting study notes, examples, and questions. Notes and demo accounts are stored in memory, so they reset when the server restarts.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

Use the demo account to sign in:

- Email: `learner@example.com`
- Password: `learning123`

New accounts created through the registration page are also kept only in memory while the server is running.
